## Lane A — API Authentication

API key authentication middleware with tenant resolution.

- Added `auth_enabled: bool = False`, `auth_api_keys: str = ""` to Settings
- Created `packages/core/src/lattice_jit/core/auth.py` — `build_auth_middleware()`, `parse_api_keys()`, `get_tenant_id()`
- API key format: `key=tenant_id,key2=tenant_id2` (comma-separated, env-configurable)
- Middleware validates `X-API-Key` header, injects `request.state.tenant_id`
- Default `auth_enabled=False` preserves full backward compatibility
- `GET /healthz` and `GET /v1/opa/health` excluded from auth
- `get_tenant_id()` dependency reads from middleware state, falls back to query param when auth disabled

## Lane B — Rate Limiting

Per-tenant sliding window rate limiting with three endpoint tiers.

- Created `packages/core/src/lattice_jit/core/rate_limit.py` — `RateLimiter`, `build_rate_limit_middleware()`
- Three tiers: ingest (10/min default), query (60/min default), export (5/min default)
- Configurable via `rate_limit_enabled`, `rate_limit_max_per_minute`, `rate_limit_ingest_max_per_minute`, `rate_limit_export_max_per_minute`, `rate_limit_window_seconds`
- `429 Too Many Requests` with `Retry-After` header when limits exceeded
- Health endpoints excluded
- Default `rate_limit_enabled=False` preserves backward compatibility

## Lane C — model2vec Embedding Router

Lightweight CPU-optimized semantic embeddings for the hybrid router.

- Created `packages/runtime/src/lattice_jit/runtime/embedding.py` — `EmbeddingService`, `cosine_similarity()`
- Uses MinishLab `model2vec` with `potion-base-8M` (~30MB, NumPy-only, no GPU)
- Lazy loading: model downloaded on first use, only when `embedding_enabled=True`
- Graceful fallback: if `model2vec` not installed, logs warning and falls back to lexical similarity
- `HybridSemanticRouter` now accepts optional `EmbeddingService` — when available, replaces lexical `_semantic_similarity` with cosine similarity on dense embeddings
- Settings: `embedding_enabled: bool = False`, `embedding_model: str = "minishlab/potion-base-8M"`
- `SemanticRouter` accepts `backend_kwargs` for clean DI injection

## Lane D — Worker Health + Dead Letter Queue

Celery task hardening with retry, dead-letter queue, and health monitoring.

- Added retry policies to all 4 Celery tasks: `autoretry_for=(Exception,)`, `max_retries=3`, `retry_backoff=True`, `retry_jitter=True`, `acks_late=True`, `reject_on_worker_lost=True`
- Added task time limits: `task_soft_time_limit=600`, `task_time_limit=900`
- Dead-letter queue: internal `_dlq_handler_task` pushes failed task payloads to Redis list `lattice_jit:dlq`
- `GET /v1/worker/health` — checks Redis broker connectivity, returns `{status, broker}`
- `GET /v1/worker/dlq` — exposes dead-letter queue entries with pagination
- Settings: `celery_task_max_retries: int = 3`, `celery_task_soft_time_limit: int = 600`, `celery_dlq_enabled: bool = True`

## Lane E — SharePoint Connector

Microsoft Graph API-based SharePoint document ingestion.

- Created `packages/connectors/sharepoint/` package (pyproject.toml, service, init, py.typed)
- `SharePointSnapshotService` with two-phase ingestion pattern
- Azure AD client credentials auth flow (`login.microsoftonline.com/{tenant}/oauth2/v2.0/token`)
- Site URL → Graph API site ID resolution, document library (drive) discovery by name
- Recursive file enumeration with `@odata.nextLink` pagination, glob pattern filtering
- Office document extraction: `.docx` via `python-docx`, `.xlsx` via `openpyxl`, `.pptx` via `python-pptx`
- Plain text extraction: `.txt`, `.md`, `.csv`
- SOURCE node per site, SECTION nodes per file with BELONGS_TO edges
- `POST /v1/snapshots/sharepoint` endpoint, `ljit ingest sharepoint` CLI command

## Lane F — Confluence Connector

Atlassian REST API-based Confluence space/page ingestion.

- Created `packages/connectors/confluence/` package (pyproject.toml, service, init, py.typed)
- `ConfluenceSnapshotService` with two-phase ingestion pattern
- Basic Auth via username + API token
- Page listing via `/rest/api/content/search?cql=space={key}&expand=body.storage`
- Confluence Storage Format HTML → plain text via `html2text`
- SOURCE node per space, SECTION nodes per page with BELONGS_TO edges
- Paginated API traversal via `_links.next`
- `POST /v1/snapshots/confluence` endpoint, `ljit ingest confluence` CLI command
